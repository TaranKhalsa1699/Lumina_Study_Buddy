# Lumina: Your AI-Powered Study Buddy 🎓

Lumina is a premium AI study assistant designed to help students master complex topics, summarize daunting study notes, and test their knowledge effectively.

## 🚀 Features

- **Notes Summarizer:** Upload PDF lecture notes and get instant, structured summaries.
- **Concept Explainer:** Get ELI5 (Explain Like I'm 5) breakdowns of any topic using powerful AI.
- **Quiz Master:** Automatically generate multiple-choice quizzes from your study material.
- **Flashcards:** Create digital flashcard decks for active recall and better retention.
- **Blazing Fast:** Powered by **Groq Llama 3** for near-instant responses.

## 🛠️ Tech Stack

- **Frontend:** [Streamlit](https://streamlit.io/)
- **LLM API:** [Groq Cloud](https://console.groq.com/)
- **Text Processing:** PyPDF2
- **Styling:** Custom CSS (Modern/Premium Aesthetic)

## 📋 Prerequisites

1.  **Python 3.8+**
2.  **Groq API Key:** Get your free key from [Groq Console](https://console.groq.com/).

## ⚙️ Installation

1.  Clone the repository:
    ```bash
    git clone <your-repo-url>
    cd Lumina_Study_Buddy
    ```

2.  Install dependencies:
    ```bash
    pip install streamlit groq python-dotenv pypdf2 pandas
    ```

3.  Run the application:
    ```bash
    streamlit run app.py
    ```

## 💡 How to Use

1.  Launch the app and enter your **Groq API Key** in the sidebar.
2.  Navigate through the different modules (Summarizer, Explainer, etc.).
3.  Upload your PDFs or type in topics to start learning smarter, not harder!
